# 🌱 Эко-активист: личный сайт с трекером эко-привычек

Лабораторная работа №5 по веб-технологиям.
Тема: **«Эко-активист»** — список эко-привычек с прогрессом.

## Описание

Одностраничный сайт-визитка эко-активиста. Кроме информации о себе (навыки, проекты, форма обратной связи) на сайте есть интерактивный **трекер эко-привычек**: пользователь добавляет привычки, отмечает выполнение, а прогресс каждой привычки отображается прогресс-баром в процентах. Привычки, прогресс и выбранная тема **сохраняются в `localStorage`** и восстанавливаются после перезагрузки страницы.

## Возможности

- **Карточки привычек** — у каждой есть название, прогресс-бар с процентами и кнопка «Отметить».
- **Добавление привычки** — название вводится в поле, после нажатия на «Добавить привычку» (или клавиши Enter) создаётся новая карточка. Пустое название не принимается.
- **Удаление привычки** — у каждой карточки есть кнопка «Удалить». Если карточек не осталось, показывается подсказка.
- **Отметка выполнения** — каждый клик по «Отметить» увеличивает прогресс на 10 %. На 100 % кнопка блокируется и меняется на «Выполнено».
- **Сброс прогресса** — кнопка «Сбросить прогресс» обнуляет все прогресс-бары.
- **Скрытие секции** — кнопка «Скрыть привычки» прячет секцию с карточками, повторный клик показывает её снова.
- **Смена темы** — кнопка «Тёмная тема» / «Светлая тема» в шапке переключает оформление.
- **Сохранение данных** — список привычек, их прогресс и тема хранятся в `localStorage` (обновляются при добавлении, удалении, отметке, сбросе и смене темы).
- **Обработка ошибок** — если на странице нет нужного элемента, скрипт не падает, а выводит понятное сообщение.

## Как это устроено

### Прогресс-бар

Прогресс-бар состоит из двух вложенных `div`:

```html
<div class="progress">                 <!-- внешний блок (трек) -->
    <div class="progress__fill"></div> <!-- внутренний блок (заливка) -->
</div>
```

Ширина внутреннего блока задаётся в процентах через `style.width`, например `fill.style.width = '40%'`. Плавность анимации обеспечивает CSS-свойство `transition`.

### Работа с DOM

Поиск элементов:

- `getElementById()` — элементы с уникальным `id` (`#habits-container`, `#status`, `#habit-input`, `#habits-section`, `#theme-toggle`);
- `querySelector()` — один элемент по CSS-селектору (кнопки в `bindClick()`, части карточки: `.progress__fill`, `.habit-card__percent`);
- `querySelectorAll()` — группа элементов (все карточки `.habit-card` при сбросе прогресса и сохранении).

Изменение DOM:

- **текст** — `textContent` (название, проценты, текст кнопок);
- **атрибуты** — `setAttribute()` (`role`, `aria-valuenow`, `aria-label`) и `dataset` (`data-progress`);
- **классы** — `className` и `classList.toggle()` (`hidden`, `dark`, `status--error`);
- **стили** — `style.width` у заливки прогресс-бара;
- **добавление элементов** — `createElement()` и `appendChild()`;
- **удаление элементов** — `card.remove()`.

### Основные функции `script.js`

| Функция | Что делает |
|---|---|
| `showMessage(text, isError)` | Выводит сообщение в блок `#status` (ошибки дополнительно пишутся в консоль) |
| `getContainer()` | Ищет контейнер `#habits-container`. Если его нет, выводит ошибку и возвращает `null` |
| `bindClick(selector, handler)` | Назначает обработчик клика, предварительно проверив, что элемент существует |
| `createHabitCard(title, progress)` | Создаёт карточку привычки через `createElement` |
| `addHabit(title, progress)` | Добавляет карточку в контейнер через `appendChild` |
| `setProgress(card, value)` | Обновляет ширину заливки, текст с процентами и состояние кнопки |
| `markHabit(card)` | Увеличивает прогресс карточки на `STEP` (10 %) и сохраняет данные |
| `removeHabit(card)` | Удаляет карточку из DOM и обновляет `localStorage` |
| `updateEmptyState()` | Показывает или убирает подсказку «Привычек пока нет» |
| `resetProgress()` | Обнуляет прогресс у всех карточек и сохраняет данные |
| `toggleHabits()` | Показывает или скрывает секцию `#habits-section` |
| `toggleTheme()` / `applyTheme()` / `restoreTheme()` | Переключают, применяют и восстанавливают тему |
| `saveHabits()` / `loadHabits()` | Сохраняют и читают список привычек из `localStorage` |
| `restoreHabits()` | При загрузке показывает сохранённые привычки (или привычки по умолчанию) |

Шаг прогресса меняется константой `STEP` в начале `script.js`. Привычки, которые появляются при первом заходе на сайт, задаются массивом `DEFAULT_HABITS`.

### Сохранение в localStorage

| Ключ | Что хранится | Пример значения |
|---|---|---|
| `ecoHabits` | JSON-массив привычек с прогрессом | `[{"title":"Сортировать мусор","progress":40}]` |
| `theme` | Выбранная тема | `"dark"` или `"light"` |

Как это работает:

1. При добавлении и удалении привычки, клике по «Отметить» и сбросе прогресса вызывается `saveHabits()`. Она собирает данные со всех карточек и записывает их через `localStorage.setItem()` в виде JSON-строки (`JSON.stringify`).
2. При загрузке страницы `restoreHabits()` вызывает `loadHabits()`, которая читает данные через `localStorage.getItem()` и превращает строку обратно в массив (`JSON.parse`). Данные проверяются: «битые» записи отбрасываются.
3. Если в `localStorage` ничего нет (первый заход), показываются привычки из `DEFAULT_HABITS`.

Посмотреть сохранённые данные можно в DevTools: **F12 → Application → Local Storage**.

### Смена темы

JS добавляет или убирает класс `dark` у `body` через `classList.toggle('dark', isDark)`. Цвета тёмной темы описаны в конце `style.css` правилами вида `body.dark ...`. Выбор темы сохраняется в `localStorage` и применяется при следующем открытии сайта.

### Обработка ошибок

- `getContainer()` проверяет, что контейнер для карточек существует. Если `querySelector` вернул `null`, в консоль пишется `console.error`, а под кнопками показывается красное сообщение.
- Обработчики кнопок назначаются через `bindClick()`, которая проверяет наличие элемента перед назначением обработчика.
- Запуск скрипта и вся работа с `localStorage` обёрнуты в `try/catch`.
- Пустое название привычки не принимается, выводится подсказка.

**Как проверить обработку ошибок:** в `index.html` измените `id="habits-container"` на любое другое значение и обновите страницу. Сайт продолжит работать, а под кнопками появится сообщение о том, что контейнер не найден.

## Соответствие заданию

| Требование | Реализация |
|---|---|
